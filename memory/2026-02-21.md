### Architecture
- Routes: `POST /api/cases`, `POST /api/cases/:id/documents`, `POST /api/cases/:id/run`, `GET /api/cases/:id/status`, `GET /api/reports/download/:token`
- Services: claudeService (dual output REPORT_BODY + EXTRACTION_JSON), pdfService (Puppeteer), emailService (Resend SMTP), storageService (R2), benchmarkService, extractionService
- Workers: analysisWorker (full orchestration), aggregationJob (flywheel)
- PDF parsing: `pdf-parse@1.1.1` + `mammoth` for DOCX
- Redis/Bull: disabled by default; set `REDIS_ENABLED=true` to enable queue
